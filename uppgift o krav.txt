Konferensen äger rum i Göteborg och är uppdelad på tre dagar, 17/10 till 19/10.

Det ska finnas minst 10 seminarier, fördelat på de tre dagarna. Du ska hitta på realistiska namn och beskrivningar.
Man kan anmäla sig till hela konferensen, eller köpa dagspass för specifika dagar. (Man kan vara med på 1, 2 eller 3 dagar. Dagarna måste inte vara i följd.)
En anmälan ska även innehålla namn, adress och e-postadress.
Man kan beställa mat, som kan vara antingen kött, fisk eller vegetarisk. Med möjlighet att anmäla allergier.
Alla formulärfält ska valideras med HTML-attribut. Använd pseudoklassen :invalid i CSS för att styla fält som har felaktiga värden.
Sidan ska vara responsiv, dvs fungera på både breda och smala skärmar.



Din chef har dessutom några krav till, som handlar om att sidan ska byggas med tillräcklig kvalité. (Du ska uppfylla kursmålen.)
Korrekt HTML och CSS (sidorna validerar)
Modern CSS (flexbox och/eller grid för layout)
Tillgänglighetsanpassad och semantisk HTML
Alla sidor ska vara responsiva
All kod ska versionshanteras med Git och GitHub
Sidan ska publiceras med GitHub Pages
För att dina kollegor ska kunna samarbeta med dig i projektet, ska du använda Git:
Du ska ha brancherna main, dev och minst en feature-branch
Du får inte skriva kod i main och dev, utom för att lösa konflikter
Du ska använda pull request när du skickar data mellan dina branches
När du lämnar in ska main-branchen innehålla den senaste versionen av koden
